# Kilder

- `jeanettes-eget-udkast.pdf` – Jeanettes første Canva-forsøg, kun brugt til stil/stemning og de tidligste kontaktoplysninger.
- `hjemmesidetekst-fra-jeanette.pdf` – den fulde, færdigskrevne hjemmesidetekst hun sendte bagefter. Dette er hovedkilden – al brødtekst på selve siden stammer herfra.

Gemt her som reference, så teksten på siden altid kan tjekkes op mod originalen.
Se `indhold/00-fakta-og-kilder.md` for hvilket felt der kommer fra hvilken kilde.
